# Журнал проблем и замечаний (issues.md)

В данном файле фиксируются проблемы, обнаруженные в процессе разработки и тестирования, а также способы их решения.

| ID | Описание проблемы | Статус | Решение |
|---|---|---|---|
| 1 | Необходимость поддержки ссылок Cloudinary без дублирования параметра `f_auto,q_auto` при повторном сохранении | OK | В хелпере `opt(u)` добавлено условие `!/\/f_auto/.test(u)`, гарантирующее идемпотентность преобразования. |
| 2 | Синхронизация порядка работ (`order`) между языковыми версиями `works_ru` и `works_en` | OK | При перемещении карточки `↑`/`↓` порядок обновляется в обеих базах (`works_ru` и `works_en`), а при отсутствии объекта во втором языке создается полная копия. |
| 3 | Сохранение состояния выбранного тега и строки поиска при перерисовке сетки | OK | Состояние `worksSearchQuery`, `worksSelectedTag` и `blogSearchQuery` сохраняется в переменных модуля и корректно применяется при динамических обновлениях. |
| 4 | Отмена удаления при задержке сети или закрытии страницы | OK | Сохранение полных резервных копий обоих языков до выполнения `dbDel` и восстановление через `dbPut` по клику на кнопку «Отменить» в тосте. |
| 5 | Кнопки в `.card-actions` переполняли контейнер и обрезались | OK | В `admin.css` внедрена компактная гибкая схема `flex-wrap: wrap; gap: 8px;`, кнопки с `flex: 0 0 auto; padding: 8px 12px; font-size: 12px;`, кнопки порядка `.btn-icon` с `32x32px`. |
| 6 | Кнопка «Дублировать» отображалась в портфолио, где она не требовалась | OK | В `admin.js` рендеринг кнопки «Дублировать» ограничен условием `mode === 'posts'` (только блог). |
| 7 | Выпадающий список `select.inp` тегов имел белый цвет фона по умолчанию на некоторых браузерах | OK | В `admin.css` добавлена темная тема `select.inp { background: #161616; color: var(--text); }` с темными опциями (`#1e1e1e` / `#333`). |
| 8 | В модалке редактирования поста блога отображались поля портфолио (Теги) вместо даты и полного текста записи, а превью фото деформировалось | OK | В `setupFieldsForMode`, `openEdit`, `duplicateItem` и `editForm.onsubmit` добавлена поддержка режимов `'posts'` и `'blog'`. В `admin.css` исправлены стили `.modal-box` (добавлен скролл `max-height: 90vh; overflow-y: auto;`) и `.ph-upload`/`.upload-previews` (убрано абсолютное позиционирование `img`). |

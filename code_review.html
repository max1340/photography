как прислать проект на доработку

(01) Процесс

Присылай проект текстом прямо в чат

Я читаю код непосредственно из сообщения: ссылки и репозитории мне не открыть, а текст — да. Самый надёжный способ — собрать проект в одно сообщение упаковщиком ниже: структура + содержимое каждого файла с именем. Дальше я верну готовые файлы целиком — просто заменишь.

(02)

Правила отправки

1

Один файл — один блок. Сверху укажи путь: «Файл: index.html». Так правки будут точно привязаны к именам.

2

Начни с главного. Структура + index.html + стили + скрипты. Если понадобится остальное (переводы, компоненты) — я попрошу.

3

Без лишнего. Не нужны node_modules, сборки и библиотеки с CDN — только твой собственный исходный код.

4

Большой проект — по частям. Если суммарно больше ~100–150 КБ текста, присылай в 2–3 сообщениях подряд.

5

Задача — отдельно. Конкретно опиши, что правим и что не трогаем (например: «левый навигатор убираю сам, его не смотри»).

(03)

Упаковщик проекта в одно сообщение

2. Опиши задачу

3. Скопируй результат
